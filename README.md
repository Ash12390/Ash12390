## Featured Work

### 1. Innivo — Hotel Management & Operating System (PMS)
*Enterprise-Grade SaaS • High Architectural Complexity*

A comprehensive multi-tenant operating system managing end-to-end hotel operations, financial ledgers, and guest lifecycles.

- **Live URL**: [innivo.online](https://www.innivo.online/)
- **Stack**: React 18, TypeScript, Supabase (PostgreSQL), Tailwind CSS, TanStack Query, PWA
- **Scale & System Complexity**:
  - **Relational Interconnectivity**: Architected 20+ deeply linked database models (rooms, bookings, guests, folios, staff RBAC, and rate rules) governed by PostgreSQL Row Level Security (RLS).
  - **Offline Sync & State Machine**: Built a client-side transaction queue with IndexedDB (`idb-keyval`) allowing full front-desk functionality during internet drops, with conflict-free FIFO synchronization on reconnect.
  - **Dynamic Yield & Pricing Engine**: Automated rate optimization algorithms evaluating real-time occupancy percentages, weekend surges, and seasonal thresholds.
  - **Statutory Tax & Financial Engine**: Native Indian GST compliance (CGST/SGST/IGST routing based on state codes) paired with client-side vectorized PDF tax invoicing (`jsPDF`).
  - **Real-Time Booking Matrix**: Drag-and-drop interactive Gantt timeline handling concurrent room assignments and split reservations.

*Targeted Production Micro-SaaS • Multimodal Vision Pipeline*

### 3. FoodSafe — AI Dietary & Allergen Scanner
*Mobile-First AI Utility • Computer Vision & Dietary Rule Engine*

A camera-first dietary safety assistant that analyzes meal photos and packaging labels to prevent severe allergic reactions.

- **Stack**: React / Next.js, Computer Vision APIs, Tailwind CSS
- **Scope & Complexity**:
  - Ingests user camera feeds, runs vision inference to detect visible food items and OCR text on ingredient packaging.
  - Cross-references identified ingredients against personalized allergen databases (nuts, gluten, dairy, shellfish) to calculate cross-contamination risk scores.
  - Delivers immediate safety ratings and ingredient breakdowns directly in a mobile viewport.
